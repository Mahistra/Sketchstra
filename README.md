## 🎯 Open for Contribution

This project is built **in the open** — and **anyone can participate**. Students, beginners, developers, designers, writers, and testers. You don't need to understand the whole project before making your first contribution.

### 📘 How to use our docs

| File | What it's for |
| --- | --- |
| [plan.md](plan.md) | The vision, features, and roadmap of Sketchstra. **Read this first.** |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to pick an issue, make changes, and submit a pull request, step by step. |
| [Open issues](https://github.com/Mahistra/Sketchstra/issues) | Find the work. Look for `good first issue` and `difficulty:easy` labels to start. |

### ✨ AI tools are welcome

Using AI assistants (ChatGPT, Copilot, etc.) to help you contribute is **allowed and encouraged** — for learning, coding, and reviewing.

### 🚀 How to start

1. Read the [project plan](plan.md)
2. Read the [contributing guide](CONTRIBUTING.md)
3. Pick an [open issue](https://github.com/Mahistra/Sketchstra/issues)
4. Fork, contribute, and open a pull request 🎉

### 💻 How to launch on your laptop

```bash
git clone https://github.com/Mahistra/Sketchstra.git
cd Sketchstra
npm install
npm run dev   # open http://localhost:5173
```
