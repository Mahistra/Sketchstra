## ✨ What is Sketchstra?

Sketchstra is a **web-based visual canvas** built to make drawing on the web **feel good**.

Open it → pick a tool → draw. Edit, zoom, pan, style, undo — all smooth, all instant. Built for students, developers, designers, teachers, and anyone who likes to think visually.

> **"Don't make drawing complicated. Make the experience better."** — the project's guiding principle.

### Why Sketchstra?
- ⚡ **Instant start** — no accounts, no onboarding, open and draw
- 🧭 **Deliberately scoped** — a great canvas first, everything else later
- 🌱 **Open from day one** — a beginner-friendly codebase built in the open
- 🤝 **For everyone** — students, beginners, and pros alike

## 🧰 Tech Stack

| Layer | Technology |
| --- | --- |
| **Framework** | [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) |
| **Build** | [Vite 7](https://vitejs.dev/) |
| **Styling** | [Tailwind CSS 4](https://tailwindcss.com/) |
| **State** | [Zustand 5](https://zustand.docs.pmnd.rs/) |
| **Rendering** | HTML Canvas 2D (custom render loop + `ResizeObserver`) |
| **Backend** | None for V1 — pure client-side |

## 🚀 Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/Mahistra/Sketchstra.git

# 2. Go to the project
cd Sketchstra

# 3. Install dependencies
npm install

# 4. Start the dev server
npm run dev
```

Then open the URL shown in your terminal (usually `http://localhost:5173`).

**Sketchstra is built in the open — and you're invited.** 🎉
